## Установка

### 1. Распаковать архив

```bash
unzip bot_backup.zip -d podezd7_bot
cd podezd7_bot
```

### 2. Создать виртуальное окружение (рекомендуется)

```bash
python3 -m venv venv
source venv/bin/activate   # Linux/Mac
# или
venv\Scripts\activate      # Windows
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

## Настройка переменных окружения

Создай файл `.env` в папке с ботом:

```env
# Обязательные
TELEGRAM_BOT_TOKEN=токен_от_BotFather
ADMIN_TELEGRAM_ID=твой_числовой_Telegram_ID
CHAT_TELEGRAM_ID=-100XXXXXXXXXX   # числовой ID супергруппы (с -100)

# Необязательные — ID тредов (топиков) в группе
STATS_THREAD_ID=338         # тред для ежедневной статистики
DIGEST_THREAD_ID=2250       # тред для ночного дайджеста
INTRO_THREAD_ID=338         # тред знакомств
GENERAL_THREAD_ID=1         # общий тред (исключается из дайджеста)
VERIFY_THREAD_ID=4          # тред верификации

# Необязательно — для AI-дайджеста
OPENAI_API_KEY=sk-...

# Необязательно — секрет для веб-дашборда
SESSION_SECRET=любая_случайная_строка
```

### Как узнать CHAT_TELEGRAM_ID

1. Добавь бота @userinfobot в группу
2. Напиши `/start` — он покажет ID чата
3. ID супергруппы выглядит как `-1001234567890`

### Как узнать ADMIN_TELEGRAM_ID

1. Напиши боту @userinfobot в личку
2. Он ответит твоим числовым ID

### Как узнать ID треда (топика)

1. Зайди в нужный тред группы
2. Нажми на любое сообщение → «Поделиться» → скопируй ссылку
3. В ссылке `t.me/c/XXXXXXXXXX/YYY/ZZZ` — `YYY` это и есть thread_id

## Запуск

### Вариант 1: напрямую (с .env файлом)

Установи дополнительно:
```bash
pip install python-dotenv
```

Добавь в начало `bot.py` перед строкой `TOKEN = os.environ[...]`:
```python
from dotenv import load_dotenv
load_dotenv()
```

Затем запусти:
```bash
python3 bot.py
```

### Вариант 2: задать переменные прямо в терминале

```bash
export TELEGRAM_BOT_TOKEN=...
export ADMIN_TELEGRAM_ID=...
export CHAT_TELEGRAM_ID=...
python3 bot.py
```

### Вариант 3: systemd (Linux, автозапуск при старте сервера)

Создай файл `/etc/systemd/system/podezd7.service`:

```ini
[Unit]
Description=Podezd 7 Telegram Bot
After=network.target

[Service]
Type=simple
User=ubuntu
WorkingDirectory=/home/ubuntu/podezd7_bot
EnvironmentFile=/home/ubuntu/podezd7_bot/.env
ExecStart=/home/ubuntu/podezd7_bot/venv/bin/python3 bot.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable podezd7
sudo systemctl start podezd7
sudo systemctl status podezd7
```

## Права бота в Telegram

Бот должен быть **администратором** группы со следующими правами:

- ✅ Управление участниками (добавлять/удалять)
- ✅ Управление сообщениями (удалять сообщения)
- ✅ Управление темами (открывать/закрывать топики)
- ✅ Приглашать пользователей

Без этих прав часть функций работать не будет.

## Как работает верификация

1. Новый участник подаёт заявку на вступление в группу
2. Бот сохраняет заявку и **автоматически** отправляет ему приветственное сообщение с кнопками «Да / Нет»
3. Если бот не работал в момент заявки — при следующем запуске форма досылается автоматически
4. Человек нажимает «Да» и называет свой **этаж** и **квартиру**
5. Бот отправляет администратору уведомление с кнопками **Принять / Отклонить**
6. Если уже есть в базе — бот сразу сообщает ему об этом и уведомляет администратора
7. После одобрения жилец получает доступ в чат

Управление заявками вручную: `/pending` показывает список с кнопками и кликабельными ссылками на профили.

## Исключения для тегов (no_tag)

Отдельным жильцам можно запретить получать Telegram-подписи.
Для этого в их записи в `residents.json` нужно добавить поле:

```json
"no_tag": true
```

Такие жильцы пропускаются при массовой расстановке подписей (/settitles, кнопки в /tags).
Удалить исключение — убрать поле `no_tag` из записи.

---

## Авто-теги для новых жильцов

При регистрации нового жильца бот проверяет базу:
- Если у **всех** существующих жильцов есть одинаковый тег — новый получает его тоже
- Если хоть у одного тега нет — новому тег не ставится
- Работает и при `/adduser` и при самостоятельной верификации

## База жильцов (residents.json)

Файл хранит всех жильцов. Формат записи:

```json
{
  "123456789": {
    "name": "Имя Фамилия",
    "floor": 5,
    "flat": 348,
    "telegram": "@username",
    "telegram_link": "https://t.me/username",
    "user_id": 123456789,
    "date_added": "2026-05-24",
    "tags": ["жилец"],
    "no_tag": false
  }
}
```

- Ключ — Telegram user_id (число в виде строки)
- Для импортированных записей без user_id ключ выглядит как `import_5_348`
- `telegram: "нет"` — у жильца нет username
- `telegram_link: "tg://user?id=..."` — есть ID но нет публичного @username
- `tags` — список меток, хранимых в базе (не Telegram-подписи)
- `no_tag: true` — жилец исключён из массовой расстановки Telegram-подписей

## Возможные проблемы

**Бот не запускается — `KeyError: 'TELEGRAM_BOT_TOKEN'`**
→ Не заданы переменные окружения. Проверь `.env` файл.

**`Conflict: terminated by other getUpdates request`**
→ Запущено два экземпляра бота. Останови все и запусти один.

**`ChatAdminRequired` при установке подписей**
→ Бот должен быть администратором с правом «Управление участниками».

**Дайджест не отправляется**
→ Проверь `OPENAI_API_KEY`. Без ключа дайджест автоматически отключён.

**Сообщение верификации не удаляется**
→ Убедись что бот — администратор с правом удалять сообщения.
→ Запусти `/postverify` вручную — это обновит сохранённый ID и наладит цикл.

**Подписи (этаж/квартира) не устанавливаются**
→ Функция работает только в супергруппах с включёнными темами (forum mode).
→ Бот должен быть администратором с правом «Управление участниками».

**Кнопка «Убрать все теги» показывает 0**
→ В базе нет жильцов с полем `tags`. Сначала добавь теги через `/tagall ТЕГ` или кнопку «🏠 Поставить этаж+кв всем» в `/tags`.
